# Fonts the art scripts set type in

`LibreBaskerville-Bold.ttf` (version 1.000) is the face of the numerals painted on the Advent Calendar's
doors (`../advent.py`). It is here so that the house renders the same on any machine: it is not a font
Windows or macOS comes with, and without it the script fell back to Georgia, whose 1, 2 and 0 stand half
as tall as its 6 and 8. It is used by Blender only, to make pictures: nothing in this folder is served
by the site.
